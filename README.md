# EvoForge — liens de partage de serveur

Page « rebond » des liens de partage d'EvoForge : un lien `https://…/?ip=<ip>&port=<port>&name=<nom>` est
cliquable dans n'importe quelle messagerie et rouvre EvoForge directement sur le serveur (schéma `evoforge://`).

Adresse à coller dans EvoForge › Réglages › « Lien de partage » : l'URL de ce site (avec le `/` final).
